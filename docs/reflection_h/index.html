Introduction

Reflection and AST Construction API for JCC Pragma Macros

Discussion

This header provides APIs for: - Type introspection and lookup - Enum reflection - Struct/union member introspection - AST node construction (literals, expressions, statements)

## Usage

This header is automatically included when compiling pragma macros. All functions that require VM context use the _VM macro, which expands to __jcc_get_vm() - a builtin that returns the current VM instance during macro execution.

## Example

@code #pragma macro _Node *make_const_5() { return _AST_INT_LITERAL(5); }

int main() { int x = make_const_5(); // x == 5 return 0; } @endcode

__jcc_quote

Parse a C code template string into an AST node, substituting $1/$2/... splice points with the provided argument nodes. 

_Node *__jcc_quote(
    JCC *vm,
    const char *tmpl,
    ...);
Parameters
vm

The VM context.

tmpl

A C expression or statement as a string literal. Use $1, $2, ... to splice in argument nodes (1-indexed, reorderable, reusable). Alternatively, use $$ for sequential (left-to-right) splice points — $$ and $N cannot be mixed.

...

_Node* arguments corresponding to the splice points.

Return Value

The parsed and substituted AST node, or NULL on error.

Discussion

Template is parsed and substituted at macro-execution (compile) time; there is no runtime overhead. Expressions and statements are auto-detected. Capped at ~6 splice nodes due to the 8- register FFI limit; use __jcc_quote_n for more.

__jcc_quote_n

Array-form quasi-quote; validates the splice count and supports more than 6 splice nodes. 

_Node *__jcc_quote_n(
    JCC *vm,
    const char *tmpl,
    _Node **nodes,
    int count);
Parameters
vm

The VM context.

tmpl

A C expression or statement as a string literal with $N splice points.

nodes

Array of _Node* splice arguments.

count

Length of the nodes array. If any $K in the template exceeds count, a compile-time error is emitted.

Return Value

The parsed and substituted AST node, or NULL on error.
